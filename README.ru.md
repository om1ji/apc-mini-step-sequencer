# apc-mini-step-sequencer

Драм-секвенсор в формате VST3 под AKAI APC mini mk2. Сетка падов — редактор паттерна, кнопки под ней выбирают дорожку, фейдеры сводят громкость, а звук плагин играет сам, из своих сэмплов, синхронно с транспортом хоста.

Написан на Rust с [NIH-plug](https://github.com/robbert-vdh/nih-plug). Разрабатывался и проверялся на macOS (Apple Silicon) в Ableton Live 12. Есть парный проект, который делает то же самое как устройство Max for Live: [apc-mini-step-sequencer-max-for-live](https://github.com/om1ji/apc-mini-step-sequencer-max-for-live).

## Как это работает

Контроллер разделён как у классической драм-машины: на сетке паттерн одной дорожки.

| Элемент | Назначение |
| --- | --- |
| Два верхних ряда падов | 16 шагов одного такта по 1/16: шаги 1–8 в верхнем ряду, 9–16 — во втором сверху |
| Кнопки под сеткой | выбор дорожки (сэмпла), которая показана на сетке; дорожек 8 |
| Фейдеры 1–8 | громкость дорожек |
| Фейдер 9 | общая громкость |
| Кнопки справа, нижние шесть рядов падов | не задействованы |

Цвета падов: серый — шаг паттерна, жёлтый — включённый шаг, зелёный — шаг, который играет сейчас. Кнопка выбранной дорожки горит. Звучат все восемь дорожек одновременно, независимо от того, какая показана на сетке.

Внутри плагина:

- **MIDI-вход** (поток колбэка `midir`) слушает порт Control у APC. Нажатия падов и кнопок уходят в очередь без блокировок (`rtrb`), положения фейдеров — в атомарные переменные.
- **Аудио-поток** в начале каждого блока разбирает нажатия, берёт у хоста темп и позицию и на каждом сэмпле проверяет, не начался ли новый шаг 1/16. Поэтому удары попадают точно в сэмпл. Он смешивает до 32 голосов с линейной интерполяцией, так что сэмпл с любой частотой дискретизации звучит в правильной высоте.
- **Окно** (egui) декодирует аудиофайлы через `symphonia` и передаёт готовые сэмплы аудио-потоку через вторую очередь.
- **Фоновая задача** отправляет кадр подсветки на контроллер — только изменившиеся пады — и освобождает заменённые сэмплы, чтобы аудио-поток никогда не освобождал память сам.

Пути к сэмплам сохраняются в проекте Live и подгружаются при его открытии. Сам паттерн пока не сохраняется — см. [Ограничения](#ограничения).

## Почему так устроено

- **Плагин общается с контроллером напрямую, а не через Live.** Live не передаёт MIDI CC в VST3-плагины, поэтому фейдеры не доходили. Ноты падов через дорожку оказались ненадёжны: после повторного добавления плагина они перестали приходить. Чтение порта через `midir` работает независимо от маршрутизации дорожки.
- **У плагина всё равно объявлен MIDI-вход, который он игнорирует.** Без него Live не загружает инструмент: `plugin has instrument category, but no valid event input bus`. Ноты с этого входа отбрасываются намеренно: если читать и их, каждое нажатие сработает дважды и переключение шага отменит само себя.
- **Подсветка и освобождение сэмплов выполняются фоновой задачей.** Отправка MIDI и освобождение памяти небезопасны для реального времени; аудио-поток только собирает 64-байтный кадр и ставит его в очередь.
- **Диалог выбора файла открывается в отдельном потоке.** Если открыть его прямо из отрисовки egui, macOS во время модального цикла вызывает отрисовку повторно, паника роняет плагин, а с ним и Live.
- **`egui-baseview` лежит в репозитории** в [`vendor/egui-baseview`](vendor/egui-baseview). `baseview` уже сообщает о перетаскивании файлов на macOS и Windows, но исходный `egui-baseview` эти события отбрасывал. Копия передаёт их в egui как `hovered_files` / `dropped_files`; `Cargo.toml` подменяет зависимость через `[patch]`.
- **Громкость фейдера сглаживается на каждом сэмпле** (однополюсный фильтр, 10 мс) и идёт по квадратичной кривой, поэтому резкое движение не щёлкает.

## Структура репозитория

```
src/
  lib.rs          плагин: цикл обработки, синхронизация с транспортом, сглаживание фейдеров, фоновые задачи
  sequencer.rs    паттерн, раскладка сетки, цвета подсветки
  apc.rs          протокол APC mini mk2: номера нот и CC, палитра, midir вход и выход
  voice.rs        воспроизведение сэмплов, 32 голоса
  sample.rs       декодирование WAV / AIFF / FLAC / MP3 через symphonia
  editor.rs       окно egui: слоты сэмплов, перетаскивание, диалог выбора файла
vendor/egui-baseview/   egui-baseview с передачей перетаскиваемых файлов
xtask/                  сборщик бандла NIH-plug (cargo xtask)
bundler.toml            имя бандла: "APC Seq"
docs/diagrams/          исходник и интерактивная схема archify
```

## Что понадобится

- AKAI APC mini mk2.
- VST3-хост. Проверено только в Ableton Live 12.0.5 на macOS 26 (Apple Silicon).
- Rust, стабильная версия (собиралось на 1.93). NIH-plug подтягивается из git, поэтому для первой сборки нужен интернет.

## Сборка и установка

```bash
cargo xtask bundle apc_seq --release
```

Бандл появится в `target/bundled/APC Seq.vst3`. На macOS удобно сделать на него ссылку из пользовательской папки VST3 — тогда после каждой пересборки ничего не нужно копировать:

```bash
mkdir -p ~/Library/Audio/Plug-Ins/VST3
ln -sfn "$PWD/target/bundled/APC Seq.vst3" ~/Library/Audio/Plug-Ins/VST3/"APC Seq.vst3"
```

После пересборки удалите плагин с дорожки и добавьте заново; иногда Live нужно перезапустить.

## Настройка Ableton Live

1. **Settings → Plug-Ins:** включите **Use VST3 Plug-in System Folders** и пересканируйте плагины.
2. **Settings → Link, Tempo & MIDI:** если в Control Surface выбран **APC mini mk2**, поставьте в этом слоте **None**. Собственный скрипт Live перерисовывает пады и спорит с плагином за подсветку.
3. Создайте MIDI-дорожку и перетащите на неё **Plug-Ins → om1ji → APC Seq**. MIDI-вход дорожки не важен: плагин читает контроллер сам.
4. Откройте окно плагина и загрузите сэмплы.
5. Нажмите Play в Live и включите шаги на двух верхних рядах.

## Использование

**Загрузка сэмплов.** Перетащите файл из браузера Live на строку дорожки в окне плагина. Пока файл над окном, строка под курсором подсвечивается. Кнопка **Загрузить…** открывает диалог выбора файла, **▶** — прослушать сэмпл. Подходят WAV, AIFF, FLAC и MP3, моно или стерео, с любой частотой дискретизации.

**Программирование.** Кнопкой под сеткой выберите дорожку и включайте шаги на двух верхних рядах. Шаги можно менять и во время воспроизведения, и на остановленном транспорте.

**Сведение.** Контроллер не сообщает положение фейдеров, пока их не сдвинуть, поэтому до первого движения плагин считает, что каждый фейдер стоит на 80 %.

Окно плагина на русском. Что в нём может встретиться:

| Текст | Значение |
| --- | --- |
| `Контроллер подключён` / `Контроллер не найден` | порт Control у APC открыт / не найден |
| `Перетащите сэмпл из браузера Live на строку дорожки` | подсказка, как загрузить сэмпл |
| `— пусто —` | у дорожки нет сэмпла |
| `Загрузить…` | открыть диалог выбора файла |

## Тесты

```bash
cargo test --lib
```

Тесты проверяют секвенсор: раскладку шагов на пады и обратно и переключение шагов у выбранной дорожки. Тайминг, звук и работа с контроллером проверяются вручную в Live.

## Решение проблем

| Симптом или сообщение | Причина и что делать |
| --- | --- |
| Live: `plugin has instrument category, but no valid event input bus` | в сборке нет MIDI-входа; `MIDI_INPUT` в `src/lib.rs` должен оставаться `MidiConfig::Basic` |
| Пады мигают или показывают цвета клипов Live | подсветкой управляет скрипт Control Surface (APC mini mk2); поставьте в этом слоте None |
| В окне `Контроллер не найден` | контроллер отключён или порт называется иначе; плагин ищет порт, в имени которого есть `APC mini mk2`, но нет `Notes` и который не начинается с `MIDIIN…` или `MIDIOUT…` |
| Фейдеры не действуют до первого движения, потом громкость скачет | так и задумано: начальное положение неизвестно, пока фейдер не пришлёт значение |
| В строке `диалог не открылся — перетащите файл` | диалог выбора файла не открылся; перетащите файл на строку |
| `неизвестный формат`, `кодек не поддерживается`, `в файле нет аудио` | `symphonia` не смогла прочитать файл; переконвертируйте его в WAV |
| Live упал при нажатии **Загрузить…** | сборка старее той, где диалог переехал в отдельный поток; пересоберите из текущих исходников |

## Ограничения

- **Паттерн не сохраняется** в проекте Live. Пути к сэмплам сохраняются, а шаги после переоткрытия проекта пустые.
- **Один такт, 16 шагов, 4/4.** Длинные паттерны поместились бы на нижние ряды падов, но не сделаны.
- **Сэмплы запоминаются по абсолютному пути.** Если переместить файлы, ссылка сломается и слот останется пустым.
- **На Windows не проверялось.** Собраться должно, но классический MIDI-драйвер Windows даёт открыть порт только одной программе. Если APC уже открыт в Live, вход `midir` в плагине может не подключиться.
- **Не запускайте вместе с версией для Max for Live** на одном контроллере — обе перерисовывают пады.
