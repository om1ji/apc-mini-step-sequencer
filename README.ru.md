# APC Seq

Драм-машина в виде плагина для AKAI APC mini mk2. Включайте шаги на сетке падов, переключайте барабаны кнопками под ней, сводите фейдерами — APC Seq сам играет ваши сэмплы в такт с хостом, без MIDI-маппинга и Drum Rack.

Это VST3-инструмент, проверенный в Ableton Live 12 на macOS. Если хочется управлять Drum Rack и видеть паттерн прямо в цепочке устройств Live, возьмите [apc-mini-step-sequencer-max-for-live](https://github.com/om1ji/apc-mini-step-sequencer-max-for-live) — версию для Max for Live.

## Что умеет

- **Паттерны из 16 шагов для восьми барабанов.** Два верхних ряда падов — один такт шагами по 1/16; каждая из восьми кнопок под сеткой показывает свой барабан.
- **Пады горят как у настоящего степ-секвенсора:** серые шаги, жёлтые удары и зелёный огонёк, бегущий вместе с транспортом хоста.
- **Играет свои сэмплы.** Перетащите в окно плагина файлы WAV, AIFF, FLAC или MP3, по одному на барабан. Сэмплы сохраняются вместе с проектом.
- **Фейдеры сводят набор.** Фейдеры 1–8 управляют громкостью барабанов, фейдер 9 — общей громкостью; громкость меняется плавно, без щелчков.
- **Точный тайминг.** Удары попадают ровно в начало шага и следуют за темпом, лупами и перемоткой хоста.
- **Ничего не нужно настраивать на дорожке.** Плагин сам общается с контроллером, MIDI-маршрутизация не нужна.

## Что понадобится

- AKAI APC mini mk2.
- VST3-хост. Проверено только в Ableton Live 12.0.5 на macOS (Apple Silicon).
- macOS на Apple Silicon или Intel. На Windows не проверялось.

## Установка

1. Скачайте `APC-Seq-0.1.0-macOS-VST3.zip` из [последнего релиза](https://github.com/om1ji/apc-mini-step-sequencer/releases/latest) и распакуйте.
2. Скопируйте `APC Seq.vst3` в `~/Library/Audio/Plug-Ins/VST3` (в Finder: **Переход → Переход к папке…**, вставьте путь; если папки `VST3` нет, создайте её).
3. Плагин не заверен Apple, поэтому macOS блокирует его после скачивания. Один раз снимите блокировку в Терминале:

   ```bash
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"APC Seq.vst3"
   ```

### Сборка из исходников

Если установлен [Rust](https://rustup.rs), из папки репозитория:

```bash
cargo xtask bundle apc_seq --release
mkdir -p ~/Library/Audio/Plug-Ins/VST3
ln -sfn "$PWD/target/bundled/APC Seq.vst3" ~/Library/Audio/Plug-Ins/VST3/"APC Seq.vst3"
```

Первая сборка скачивает зависимости и занимает несколько минут. Ссылка обновляет установленный плагин после каждой пересборки.

## Настройка Live

1. **Settings → Plug-Ins:** включите **Use VST3 Plug-in System Folders** и пересканируйте плагины.
2. **Settings → Link, Tempo & MIDI:** если в Control Surface выбран **APC mini mk2**, поставьте в этом слоте **None**, иначе Live будет перерисовывать пады.
3. Создайте MIDI-дорожку и перетащите на неё **Plug-Ins → om1ji → APC Seq**. MIDI-вход дорожки не важен.
4. Откройте окно плагина и загрузите сэмплы (см. ниже).
5. Нажмите Play и включите шаги на двух верхних рядах.

## Как играть

| Элемент | Что делает |
| --- | --- |
| Два верхних ряда падов | шаги 1–8 в верхнем ряду, 9–16 — во втором сверху; нажатие включает или выключает шаг |
| Кнопки под сеткой | выбор барабана для редактирования, с 1 по 8 |
| Фейдеры 1–8 | громкость барабанов 1–8 |
| Фейдер 9 | общая громкость |

Шаги можно менять и во время воспроизведения, и на остановленном транспорте. Звучат все восемь барабанов сразу, какой бы ни был показан на сетке. Все удары звучат с одинаковой силой.

Контроллер не сообщает, где стоят фейдеры, пока их не сдвинуть, поэтому до первого движения плагин считает, что каждый фейдер стоит на 80 %.

### Загрузка сэмплов

Перетащите файл из браузера Live на строку барабана в окне плагина — пока вы тянете файл, строка подсвечивается. Кнопка **Загрузить…** открывает диалог выбора файла, **▶** проигрывает сэмпл.

Окно плагина на русском:

| Текст | Значение |
| --- | --- |
| `Контроллер подключён` / `Контроллер не найден` | APC подключён / не найден |
| `Перетащите сэмпл из браузера Live на строку дорожки` | подсказка, как загрузить сэмпл |
| `— пусто —` | сэмпл не загружен |
| `Загрузить…` | загрузить файл |

## Если что-то не работает

| Что видно | Что делать |
| --- | --- |
| Live не видит APC Seq, или macOS пишет, что его нельзя открыть | скачанный файл ещё заблокирован: выполните команду `xattr` из [Установки](#установка) и пересканируйте плагины |
| В окне `Контроллер не найден` | проверьте USB-кабель; плагин ищет MIDI-порт с именем вроде `APC mini mk2 Control` |
| Пады мигают или показывают цвета клипов | подсветкой управляет ещё один скрипт: Control Surface APC mini mk2 в Live или версия APC Seq для Max for Live |
| Фейдеры не действуют до первого движения, потом громкость скачет | так и задумано: положение фейдера плагин узнаёт при первом движении |
| `диалог не открылся — перетащите файл` | диалог выбора файла не открылся; перетащите файл на строку |
| `неизвестный формат`, `кодек не поддерживается` или `в файле нет аудио` | файл не удалось прочитать; переконвертируйте его в WAV |
| Барабан замолчал после того, как переместили файлы сэмплов | сэмплы запоминаются по расположению на диске; загрузите файл заново |

## Ограничения

- Паттерн пока не сохраняется вместе с проектом. Сэмплы сохраняются, а шаги после переоткрытия пустые.
- Один такт из 16 шагов в размере 4/4. Длинных паттернов и других размеров пока нет.
- На Windows не проверялось. Windows обычно даёт пользоваться MIDI-портом только одной программе, поэтому плагин может не увидеть контроллер, пока он открыт в Live.
- Кнопки справа и нижние шесть рядов падов не задействованы.
- На одном контроллере используйте либо этот плагин, либо версию для Max for Live, но не обе сразу.
